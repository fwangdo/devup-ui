# Box

The `Box` component is a **layout primitive** designed for flexible composition.
It follows **JSX syntax** — you can define elements with `<Box ... />` and pass style properties directly as props.

It supports **multiple styling syntaxes**, including:

- **Pure React style props** (e.g. `bg="red"`, `flex={1}`)
- **Tailwind-like shorthand** (e.g. `p={4}`, `mt={2}`, `text="center"`)

You can freely mix both styles depending on your preference.

---

## How It Works

`Box` is essentially a styled `div` that translates its props into CSS classes and inline styles.
You can think of it as the foundation for layout and spacing, similar to how Tailwind or styled-components work — but unified into a single declarative interface.

If you pass a number without a unit, it is automatically **scaled by 4**
(so `1` → `4px`, `2` → `8px`, `3` → `12px`, and so on).

However, the following properties **are not multiplied by 4**:

- `opacity`
- `flex`
- `z-index`
- `line-clamp`
- `font-weight`
- `line-height`
- `scale`
- `aspect-ratio`
- `flex-grow`
- `flex-shrink`
- `order`
- `grid-column`, `grid-column-start`, `grid-column-end`
- `grid-row`, `grid-row-start`, `grid-row-end`
- `animation-iteration-count`
- `tab-size`, `moz-tab-size`, `-webkit-line-clamp`

---

## Example (React-style props)

```tsx
import { Box } from '@devup-ui/react'

function App() {
  return <Box bg="red" flex={1} height={100} width={100} />
}
```

Rendered result:

```tsx
function App() {
  return <div className="a b c d" />
}
```

```css
.a {
  background: red;
}
.b {
  flex: 1;
}
.c {
  height: 100px;
}
.d {
  width: 400px;
}
```

---

## Example (Tailwind-like syntax)

```tsx
import { Box } from '@devup-ui/react'

function App() {
  return (
    <Box className="p-4 mt-2 bg-blue-500 text-center rounded-lg">
      Hello DevUp!
    </Box>
  )
}
```

This will render a `div` with equivalent Tailwind-like styles applied.

---

## Rendering as Another Element

You can change the rendered HTML element using the `as` prop:

```tsx
import { Box } from '@devup-ui/react'

function App() {
  return <Box as="span" bg="red" />
}
```

Which compiles to:

```tsx
function App() {
  return <span className="a" />
}
```

```css
.a {
  background: red;
}
```

## Knowledge for Contribution: Available CSS Props in Box

The `Box` component supports a wide range of CSS properties, pseudo-classes, and theme-based props.
Developers don’t need to know all the internal details, but here’s a brief overview of how these props are defined at the type level.

---

## Core Snippet (Type-Level Definition)

```ts
import type { Pseudos } from 'csstype'

import type { DevupProps } from '../index'

export type NormalSelector = Exclude<
  Pseudos,
  `:-${string}` | `::-${string}` | `${string}()`
>

export type ExtractSelector<T = NormalSelector> = T extends `::${infer R}`
  ? R
  : T extends `:${infer R}`
    ? R
    : never

export type CommonSelectorProps = {
  [K in ExtractSelector as
    | `_${CamelCase<K>}`
    | `_group${PascalCase<K>}`]?: ResponsiveValue<DevupProps | string | false>
}
```

- `Pseudos` from `csstype` provides all CSS pseudo-classes and pseudo-elements.
- `ExtractSelector` strips the leading `:` or `::` from pseudo-class/element names.
- `CommonSelectorProps` maps each pseudo selector to a typed prop (e.g., `_hover`, `_groupHover`) and allows **all base CSS props (`DevupProps`) as values**.

Note: Internally, Box prop strings are lexed at the type level to derive one or more possible prop types.
